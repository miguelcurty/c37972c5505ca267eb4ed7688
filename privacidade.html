Política de privacidade

Atualizada em 05/11/2026

Esta página explica, em linguagem simples, como este site trata as informações de quem o visita. Ela vale para o site connectimport.com.br.

Resumo: o site não usa cookies próprios, não usa ferramentas de análise de audiência e não rastreia você. O formulário de contato apenas abre o seu aplicativo de e-mail. O vídeo do YouTube só é carregado se você clicar para assistir.

Quem é responsável

O controlador dos dados tratados neste site é a Connect Import Importadora, Exportadora e Comércio Ltda, CNPJ 18.082.923/0001-03, com sede em Palhoça/SC. Para qualquer questão sobre privacidade ou sobre os seus dados, escreva para contato@connectimport.com.br.

O que o site não faz

  • Não instala cookies próprios no seu navegador.
  • Não usa ferramentas de análise de audiência, como Google Analytics.
  • Não usa pixels, rastreadores de publicidade ou perfis de navegação.
  • Não grava as informações que você digita no formulário: elas ficam apenas no seu dispositivo até você enviar o e-mail.

Formulário de contato

O formulário deste site não envia dados para um servidor. Ao clicar em enviar, ele monta uma mensagem e abre o aplicativo de e-mail do seu próprio dispositivo, já preenchida com o seu texto, para o endereço contato@connectimport.com.br. O envio só acontece se você confirmar dentro do seu aplicativo de e-mail. Nada é gravado pelo site.

Vídeo do YouTube

O vídeo institucional não é carregado quando a página abre: aparece apenas uma imagem com o botão de play. O player do YouTube só é carregado depois que você clica para assistir. A partir desse clique, o YouTube passa a aplicar as políticas e os cookies dele, que não controlamos. Se preferir não carregar o vídeo, basta não clicar.

Links para outros sites e serviços

O site tem links para WhatsApp, Instagram, YouTube e beacons.ai. Esses serviços são de terceiros: ao clicar em um deles, você passa a usar outro site ou aplicativo, com as políticas de privacidade próprias. Não temos acesso ao que é coletado por eles.

Hospedagem

A hospedagem do site registra automaticamente informações técnicas do acesso, como endereço IP, data e hora, para que a página funcione e para segurança. Esses registros são do serviço de hospedagem, não são usados por nós para identificar visitantes e não alimentam perfis de navegação.

Seus direitos

A Lei Geral de Proteção de Dados (LGPD, art. 18) garante a você, entre outros direitos, o de:

  • confirmar se tratamos algum dado seu e acessá-lo;
  • corrigir dados incompletos, inexatos ou desatualizados;
  • pedir anonimização, bloqueio ou eliminação de dados desnecessários ou excessivos;
  • pedir a portabilidade dos dados;
  • pedir a eliminação de dados tratados com base no consentimento;
  • saber com quem os dados foram compartilhados;
  • revogar o consentimento, quando o tratamento se basear nele.

Como o site não coleta dados por conta própria, na prática esses pedidos costumam se referir a mensagens que você nos enviou por e-mail. Para exercer qualquer um desses direitos, escreva para contato@connectimport.com.br.

Alterações desta política

Se o site passar a usar algum recurso que trate dados de outra forma, esta página será atualizada e a data no topo será alterada. A versão em vigor é sempre a publicada aqui.
